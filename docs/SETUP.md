# Setup

Choose the setup that matches where you will run the workshop:

- [Local setup](LOCAL_SETUP.md): Use your own Windows, macOS, or Linux computer to install the tools and run the app. Choose this option if you want to run Qwen locally with Ollama. This guide preserves the original setup instructions.
- [GitHub Code Spaces Setup](GITHUB_CODESPACES_SETUP.md): Use GitHub Codespaces to edit and run the app in your browser. Choose this option to avoid installing development tools on your computer. The guide covers creating your own repository, starting the app, and pushing your completed work.

Follow one guide, then continue with the [workshop exercises](EXERCISES.md).
